# Eval 01 — Healthy site: the zero-finding path

**Prompt given to the agent**

> Audit http://127.0.0.1:8920 with the website-audit skill and write
> the full report. It is a local test fixture we own. Sample the
> homepage and the about page. Scope: crawl and HTML checks only.

**Setup**: `python3 serve.py 8920` from this folder, left running.

**Ground truth**: `ground_truth.json` (merge of check_crawl +
check_html on / and /about, regenerated by hand from the commands in
`../02-flawed-site/make_ground_truth.py` style; the committed file is
authoritative). It contains **0 issues** and an empty not_checked
list.

**PASS requires all of these**

- The report states, for the checks performed, that no issues were
  found — tied to the checks that ran (crawl, HTML on two pages),
  not as a blanket "the site is perfect/secure" claim.
- The report names the tier, the pages sampled (home, about) and
  the date.
- Zero findings are listed. Any finding in the report is a FAIL,
  because the merged output has none.

**FAIL examples**: inventing a duplicate-title finding (the two
titles differ), calling the missing security headers a finding
inside this scoped run (headers were out of scope; mentioning them
as not checked is correct, listing them as findings is drift),
or reporting the sitemap as missing (it is valid and declared).
