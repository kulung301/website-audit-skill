# Examples

Real reports produced by this skill, kept as references for what its output
should look like.

- [example.com-audit.md](example.com-audit.md) — full Tier A+B+C audit of
  https://example.com/ (2026-11-23): 17 distinct issues.

Reports are point-in-time observations of the target as measured from one
environment. Performance numbers are single emulated lab runs, not field
data, and findings about a site describe the responses observed at audit
time.
